Guia de Front-End

Bem-vindo ao Guia Front-End: O Seu Mapa para a Web

Dominar o Front-End é muito mais do que apenas escrever código; é a arte de construir a ponte entre a tecnologia e o usuário final. Transformamos linhas de texto em interfaces interativas, visuais e acessíveis que bilhões de pessoas utilizam todos os dias.

Neste guia, você encontrará o caminho das pedras para se tornar um desenvolvedor completo. A jornada começa na fundação, passa pelo estilo e ganha vida com a lógica de programação.

HTML

HTML: A Estrutura (O Esqueleto)

O HTML (HyperText Markup Language) é o ponto de partida. Ele não é uma linguagem de programação, mas sim de marcação. É aqui que você define o que é um título, um parágrafo, uma imagem ou um link. Sem o HTML, a web seria apenas um amontoado de dados sem organização.

Cabeçalhos (<h1> a <h6>)

Definem a hierarquia e a importância do conteúdo. O <h1> é o título principal, enquanto do <h2> ao <h6> organizam as subseções.

Exemplo: <h1>Título Principal</h1>

Parágrafos e Textos <p>

A tag <p> é usada para definir blocos de texto comuns. Ela organiza o conteúdo de forma legível e adiciona espaçamento entre os parágrafos.

Exemplo: <p>Este é um parágrafo de texto.</p>

Links e Imagens (<a> e <img>)

O <a> cria hiperlinks para conectar páginas. A tag <img> insere imagens, usando src para o caminho e alt para acessibilidade.

Exemplo: <a href="#">Link</a>
<img src="foto.jpg" alt="Descrição">

CSS

CSS: O Estilo (A Pele e a Roupa)

Com o CSS (Cascading Style Sheets), damos personalidade ao site. É nesta etapa que você aprende sobre cores, tipografia, espaçamentos e, crucialmente, o Design Responsivo — garantindo que seu site seja bonito tanto em um monitor gigante quanto na tela de um celular.

Estilo e Bordas (color e border-radius)

A propriedade color define a cor da fonte do texto. O border-radius é utilizado para arredondar os cantos de elementos, como botões ou caixas de destaque.

Exemplo: color: blue;
border-radius: 10px;

Espaçamentos (margin e padding)

O padding gera espaço interno (dentro da borda do elemento), enquanto a margin cria espaço externo, definindo a distância entre o elemento e seus vizinhos.

Exemplo: padding: 20px;
margin: 15px;

Layout com Flexbox (display: flex)

Transforma o elemento em um container flexível, facilitando muito o alinhamento e a distribuição de espaço entre os itens de forma responsiva.

Exemplo: display: flex;
justify-content: center;

JavaScript

JavaScript: A Interatividade (Os Músculos)

O JavaScript é a linguagem que traz vida à página. Com ele, você cria elementos que reagem ao clique do usuário, valida formulários, carrega dados de outros sites e constrói aplicações complexas e dinâmicas. É o motor que transforma uma página estática em uma experiência real.

Seleção de Elementos (querySelector)

É o método utilizado para o JavaScript encontrar elementos no HTML. Ele usa a mesma lógica de seletores do CSS para localizar classes, IDs ou tags.

Exemplo: const botao = document.querySelector('.btn');

Lógica e Condicionais (function e if / else)

Funções executam blocos de código reaproveitáveis. O if / else controla o fluxo do site, decidindo qual ação tomar baseada em uma condição.

Exemplo:
if (x > 10) {
  alert('Maior');
} else {
  alert('Menor');
}

Escuta de Eventos (addEventListener)

Permite que o código "escute" e reaja a interações do usuário, como um clique de mouse, um toque na tela ou o pressionamento de uma tecla.

Exemplo: elemento.addEventListener('click', () => { console.log('Clicou!'); });
